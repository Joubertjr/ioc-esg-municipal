# SKILLS - IOC ESG MUNICIPAL

Este diretório contém skills (conhecimentos especializados) para o projeto IOC ESG Municipal.

## O que são Skills?

Skills são módulos de conhecimento que estendem a funcionalidade do projeto com:
- Workflows especializados
- Boas práticas
- Integrações específicas
- Processos validados

## Skills Disponíveis

### 1. API Integration Skill
**Arquivo:** `api_integration_skill.md`

Guia completo para integrar APIs de dados abertos:
- Como chamar cada API
- Tratamento de erros
- Rate limiting
- Caching de dados

### 2. Data Validation Skill
**Arquivo:** `data_validation_skill.md`

Metodologia para validar dados coletados:
- Verificações de integridade
- Detecção de anomalias
- Tratamento de dados faltantes
- Normalização de formatos

### 3. ODS Mapping Skill
**Arquivo:** `ods_mapping_skill.md`

Como mapear indicadores aos ODS:
- Matriz de mapeamento
- Cálculo de impacto
- Scoring de ESG
- Recomendações

### 4. Simulation Skill
**Arquivo:** `simulation_skill.md`

Implementação do simulador com MiroFish:
- Criação de cenários
- Cálculo de impacto
- Validação de resultados
- Geração de relatórios

### 5. Dashboard Skill
**Arquivo:** `dashboard_skill.md`

Construção do dashboard:
- Layout responsivo
- Componentes de visualização
- Interatividade
- Performance

## Como Usar Skills

### Passo 1: Ler a Skill
```bash
cat 7_SKILLS/api_integration_skill.md
```

### Passo 2: Implementar Conforme Instruções
Seguir passo a passo as instruções da skill

### Passo 3: Validar Implementação
Executar testes conforme especificado na skill

### Passo 4: Documentar Aprendizados
Atualizar skill com novos conhecimentos

## Estrutura de uma Skill

Cada skill segue este padrão:

```markdown
# [Nome da Skill]

## Objetivo
O que esta skill resolve

## Pré-requisitos
O que é necessário antes de começar

## Conceitos-Chave
Definições importantes

## Passo a Passo
Instruções detalhadas

## Exemplos de Código
Código pronto para usar

## Testes
Como validar a implementação

## Troubleshooting
Problemas comuns e soluções

## Referências
Links e documentação
```

## Criando Novas Skills

Se você descobrir um novo padrão ou processo que funciona bem:

1. Criar arquivo `nova_skill.md`
2. Documentar conforme padrão acima
3. Incluir exemplos de código
4. Testar completamente
5. Adicionar à lista acima
6. Compartilhar com equipe
